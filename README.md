## ⚡ Features & Capabilities

- 📁 **Bulk Import:** Upload website lists via `.txt`, `.csv`, or Excel (`.xlsx`) files or paste URLs directly.
- ⚡ **Direct Native Speed:** Performs direct native HTTP fetching (50ms–200ms per site) with multi-worker parallel processing (15x Parallel Workers).
- 🔄 **Parallel Proxy Racer Fallback:** Multi-proxy fallback engine (`CORSProxy.io`, `AllOrigins`, `ThingProxy`, `CodeTabs`) resolves CORS restrictions automatically.
- ✉️ **Rich Contact Extraction:** Extract Emails (direct, mailto, HTML entities, and obfuscated formats like `name [at] domain [dot] com`), Phone Numbers, and Social Media links (Facebook, Twitter/X, LinkedIn, Instagram, YouTube, GitHub, TikTok, WhatsApp).
- 🔍 **Sub-page Crawling:** Deep scan `About Us`, `Contact Us`, and `Services` pages for contact details.
- 📊 **Real-Time Tracker & Visuals:** Live metrics, step pipeline progress, Doughnut chart (Chart.js), and real-time execution console.
- 📂 **Multi-Format Data Export:** Save mined data into Excel (`.xlsx`), CSV (`.csv`), PDF (`.pdf`), JSON (`.json`), or Google Sheet TSV (`.txt`).
- 🎨 **Glassmorphism UI & Sound Chime:** Light & Dark theme toggle and Web Audio completion chime.
